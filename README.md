# Meu Portfólio Pessoal - Site

Primeiro projeto desenvolvido para aprender Git, GitHub e publicação de sites.

## 🚀 Tecnologias
- HTML5
- CSS3
- Git e GitHub
- GitHub Pages para hospedagem

## 📸 Sobre o projeto
Site pessoal criado como parte dos meus estudos iniciais em Desenvolvimento Web. Projeto focado em versionamento de código e publicação online.

## ▶️ Como visualizar
1. Clone o repositório
2. Abra o arquivo `index.html` no navegador

Ou acesse a versão online (se tiver GitHub Pages ativado).
